# Privacy Policy

**Last Updated:** October 2026

This repository hosts an internal workflow and automation tool for managing and scheduling pins via the Pinterest API.

### 1. Data Collection
This application is strictly for personal and internal operational use. It does not collect, track, store, sell, or share personal data from external visitors, third parties, or consumers.

### 2. Third-Party Services & API Usage
The tool interacts exclusively with the Pinterest API v5 to publish content and check board metadata on behalf of the account owner. Credentials and access tokens are kept private and are never exposed to outside services.

### 3. Contact
For inquiries regarding this project, open an issue directly in this repository.
